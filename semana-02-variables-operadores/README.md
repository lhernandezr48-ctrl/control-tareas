# Semana 2 - Variables y Operadores

## Descripción
Este programa en Java solicita el nombre, el carné, el año de nacimiento y el año actual para calcular la edad aproximada del estudiante, la edad en meses y verificar si es mayor de edad.

## Datos solicitados
- Nombre completo
- Carné
- Año de nacimiento
- Año actual

## Cálculos realizados
- Edad aproximada
- Edad aproximada en meses
- Verificación de mayoría de edad mediante una variable boolean.

## Instrucciones para ejecutar
1. Abrir el proyecto en IntelliJ IDEA.
2. Ejecutar la clase `CalculadoraEdad.java`.
3. Ingresar los datos solicitados en la consola.

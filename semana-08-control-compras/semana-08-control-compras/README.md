# Control de Compras

## Descripción
Aplicación de consola en Java para registrar y analizar las compras de un hogar durante una semana.

## Funcionalidades
- Registrar productos y validar sus datos.
- Calcular subtotales y el total general.
- Identificar categorías sin duplicados.
- Acumular gastos por categoría.
- Encontrar los productos de mayor y menor gasto.
- Consultar el gasto de una categoría.

## Instrucciones para ejecutar el programa
1. Abrir el proyecto en IntelliJ IDEA.
2. Abrir la carpeta `src`.
3. Ejecutar la clase `MainControlCompras`.
4. Registrar al menos cinco productos válidos.
5. Consultar una categoría al finalizar.

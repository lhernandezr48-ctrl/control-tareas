# Desafíos Lógicos

## Descripción
Programa de consola desarrollado en Java para practicar estructuras condicionales, ciclos y validaciones de datos.

## Funcionalidades
1. Generar una secuencia numérica.
2. Realizar un conteo regresivo.
3. Analizar números positivos y negativos, ignorando múltiplos de 5 en la suma.
4. Dibujar una pirámide de asteriscos.
5. Validar una palabra secreta.
6. Salir del programa.

## Tecnologías utilizadas
- Java
- Scanner
- IntelliJ IDEA

## Temas aplicados
- Condicionales: if, else if, else y switch.
- Ciclos: for, while y do while.
- Control de ciclos: break y continue.
- Validaciones numéricas y de texto.

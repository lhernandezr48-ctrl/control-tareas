# Figuras Geométricas

## Descripción
Aplicación de consola desarrollada en Java para calcular el área de diferentes figuras geométricas mediante programación orientada a objetos.

## Figuras implementadas
- Círculo
- Rectángulo
- Triángulo

## Instrucciones para ejecutar el programa
1. Abrir el proyecto en IntelliJ IDEA.
2. Verificar que los cinco archivos Java estén dentro de `src`.
3. Abrir `Main.java`.
4. Ejecutar el método `main`.

## Descripción del problema
Una tienda necesita controlar sus productos (código, nombre, categoría,
precio, stock y estado). La base de datos debe impedir códigos repetidos,
precios iguales o menores que cero, existencias negativas y productos
sin nombre o categoría.

## Requisitos para ejecutar los scripts
- PostgreSQL 14
- pgAdmin 4 (o psql)

## Nombre de la base de datos
`control_inventario`

## Orden de ejecución
1. `database/01_creacion.sql`
2. `database/02_datos_prueba.sql`
3. `database/03_operaciones.sql`
